# 360° Video Player & Evidence.com Interface

A full-stack 360° video evidence visualization tool combining a dual-fisheye player with an Evidence.com-style interface for law enforcement use.

## Features
- Dual-fisheye and equirectangular video support with seamless 3D panning  
- Timeline pinning with synchronized 2D–360° playback  
- Automatic fisheye-to-equirectangular conversion using OpenCV and FFmpeg  
- Background video export with multi-resolution output  
- Glassmorphism-inspired UI and keyboard-driven playback controls  

## Tech Stack
Python • Flask • OpenCV • FFmpeg • Three.js • HTML/CSS/JS
